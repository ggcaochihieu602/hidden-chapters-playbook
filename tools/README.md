# Dùng playbook qua GitHub

**Máy mới (lần đầu):** cài Git, rồi mở PowerShell và chạy:

    git clone https://github.com/<tên-github>/hidden-chapters-playbook.git "E:\Youtube AI\Hidden Chapters\Playbooks\Playbook ver 33"

Sau đó nhấp đúp `tools\update.bat` để cài skill Codex và LATEST.

**Cập nhật bản mới trên máy bất kỳ:** nhấp đúp `tools\update.bat` (tự `git pull` rồi cài lại skill).

Giữ đúng đường dẫn `E:\Youtube AI\Hidden Chapters\Playbooks\Playbook ver 33` vì playbook ghi đường dẫn tuyệt đối.
