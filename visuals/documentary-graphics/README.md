# Ảnh mẫu documentary — file gốc của người dùng

Mở xem ảnh thật khi làm đồ họa cơ chế/số liệu, không chỉ đọc mô tả. Các file PNG nằm ngay trong folder này, được giữ trong ZIP và có SHA256 tại SAMPLE_MANIFEST.json.
